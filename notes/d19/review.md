# D19 · 状态估计基础：LS → WLS（2026-10-10）

## 一、核心推导
- LS:  min Σ(xᵢ-x̂)² → x̂ = 平均（等权）
- WLS: min Σwᵢ(xᵢ-x̂)² → x̂ = Σwᵢxᵢ/Σwᵢ（加权平均）
- 矩阵: β̂ = (XᵀWX)⁻¹XᵀWy
- ★ 权重 = 1/σ²（方差倒数，不是 1/σ！）
  - 拉格朗日: min Σwᵢ²σᵢ² 约束 Σwᵢ=1 → wᵢ ∝ 1/σᵢ²
  - 直觉: 噪声按"功率"(σ²)计量，权重反比于功率

## 二、为什么加权（问题）
等权平均被高噪声观测拉偏；WLS 自动把烂传感器降权（σ=3 的权重仅 2%）

## 三、实测（2000 次实验，σ=[0.5,1,3]）
- 普通平均 MSE = 1.185（理论 1.139）
- WLS     MSE = 0.194（理论 0.196）✅ 吻合
- 改善 6.11 倍

## 四、衔接 D20
WLS = 高斯似然下 MAP = 卡尔曼"更新步"静态版
卡尔曼 = 递推贝叶斯（预测=先验 + 更新=似然）
